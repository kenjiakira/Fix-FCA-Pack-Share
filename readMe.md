# Fix-FCA-Pack-Share

## Cài đặt

1. Clone repository
2. Chạy `npm install` để cài đặt các dependencies

## Cấu hình

### OpenAI API Key

Để sử dụng tính năng OpenAI, bạn cần tạo file `.env` ở thư mục gốc với nội dung sau:

```
OPENAI_API_KEY=your_openai_api_key_here
```

Thay `your_openai_api_key_here` bằng API key của bạn từ [OpenAI](https://platform.openai.com/api-keys).

## Khởi động

```
npm start
```
